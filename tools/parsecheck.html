Dark Raiders parse check

This machine has no JavaScript runtime, so node --check cannot run. This is the substitute: it fetches a build, pulls the script out, and asks the browser's own parser to compile it without executing it. A build that fails here is dead on arrival and must never be reported as ready.

Default target is fixture.html in this folder, which tools/mkfixture.ps1 rebuilds from the game on every edit, so it is the same script the game runs. It is fetched same origin on purpose: the play server on 8802 sends no CORS headers, so fetching it from here fails silently and the page hangs on "checking". Add ?f=NAME.html to check another file in this folder.
