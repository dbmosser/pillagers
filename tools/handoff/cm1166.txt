v11.66: the restore code left the armoury behind

unlocked and carried no gun: not the guns owned, the one in hand, the second
slot, or the wear on any of them. Restored from it, a friend came back with
the fresh Scav Pistol. The code carries the armoury now; applying it brings
the guns back, drops any this build does not know, and an older code without
the block leaves the guns as they are. Check 11.66 makes a code from three
distinctive guns with slots and wear, wipes, applies and requires them back,
with an unknown-gun control; fails on v11.65. From the v11.46 audit, P1.
