## v13.00 - THE UNDERCROFT STOPS HITCHING ON EVERY CLICK

Finding 13 of the 2026-09-11 read-only audit, and EVERY PLAYER PAYS IT, not just this
machine. The watcher is armed unconditionally; only the click that opens the editor is
gated behind the authoring mode.

WHAT IT COSTS, MEASURED. The whole game is one file, and the style block and the entire
program live INSIDE the element the text walker is pointed at. To a text-node walker
with no filter they are simply two more text nodes. The check measured what the
rewriter is handed on one pass of the old build: a single string of 3,505,542
characters, and 3,626,573 characters in total. For that one string the rewriter runs a
whitespace-stripped copy of the whole program to decide whether it is blank, a regular
expression across the lot to pull out every number in the file, another full copy built
from the pieces, and then uses that multi-megabyte string as a lookup key.

WHEN IT FIRES. Every toast in the Undercroft, every time Credits or XP move, and every
panel rebuild: packing, tagging junk, selling, dropping. The Undercroft is the screen
he has called the ship blocker, and this is a hitch on almost every click in it.

WHY IT WAS NEVER RIGHT. The feature rewrites LABELS. A stylesheet and a program are not
labels and can never be edited, so the walk should never have been looking at them. The
font sweep at the other end of the same file has skipped SCRIPT, STYLE and CANVAS by
name for builds, so the rule was known; it was simply never applied in the place where
it was costing something.

THE BUILD. A node filter on the walk. The cost now tracks what is on screen instead of
the size of the file. Nothing visible changes.

MEASURED. Check 13.00 wraps the one function the walk calls for every node it visits
and records the length of every string handed to it. That is the defect stated as a
number: a label is a few dozen characters. It requires no single string over 20,000 and
no pass over 400,000 in total, and it separately NAMES what it found, requiring that
neither the program text nor the stylesheet arrives. No timing: a stopwatch in a hidden
pane is noise, and this cost is not a mystery to be sampled but a string length that
either is or is not the size of the file. The control is a label planted on screen,
which must still reach the rewriter, because a filter that skipped everything would
pass every other arm and silently kill the feature. Four arms fail on the v12.99
fixture.

Not verified: it measures one pass driven by hand rather than a toast or a panel
rebuild driving it, so it proves the size of the work and not the frequency; and it
does not measure elapsed time, so the improvement is stated as characters rather than
milliseconds.
