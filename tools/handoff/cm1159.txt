v11.59: a grenade on a belt key was a dead key, and it deleted the working one

From the 2026-09-06 read-only raid audit, raised by two regions independently.
The same hole the v8.31 comment records for the stim, one item type later: a
throwable lives in the pouch and never in the backpack, so the belt built it
as a plain item, which the trigger treats as a held gun. Putting a Frag Charge
on a key gave a key that fired your rifle under a caption saying use, did
nothing on the use key, read x0 while the pouch held two, and blanked the
working grenade cell; binding all three left nothing able to throw. A belted
throwable is now built exactly as the bar's own throwable cell is, and the use
key throws it. Check 11.59 binds a frag and requires a live cell, one cell,
a synced selector and a real throw; fails on v11.58.
