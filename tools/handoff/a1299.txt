Edit the words is on; he clicks a line inside any window, the yellow box opens over it, he changes his mind and presses ESC to back out, and the capture handler that gives Escape to the front window runs first, finds a modal open, stops the event dead and closes that window. The event never reaches the box, so the one gesture that means CANCEL THIS EDIT destroys the panel the edit was being made in and leaves the editor it was supposed to dismiss sitting over the game holding the keyboard. The box outlives its panel because it is appended to the document body rather than inside the screen, so closing the panel cannot take it along, and he has to press ESC a second time to be rid of it, by which point the window he was editing is gone. The handler is right and still wrong: its own comment states the rule, that if a window is open Escape belongs to that window and not to what is underneath, and the editor sits ABOVE the window at z-index 99999, so by the handler own rule Escape belongs to the editor; it simply had no way to know the editor was there. The fix goes at the top of that handler rather than in another one further down the chain, because anything downstream never runs: this one stops propagation before the box can hear the key at all, so the box own Escape line was never dead code, it was unreachable. Check 12.99 opens a window, opens the editor over it, and dispatches the key AT THE BOX, which is the point rather than a convenience, because the handler under test is a capture listener on the document and sees an event aimed at the box on the way down exactly as a real keypress in a focused input arrives, while dispatching on window would never travel through the document to the input and would prove nothing about the real path; both halves are required, the box must go and the window must STAY, because closing both is the defect with one extra step rather than a fix; the control is Escape with no box open, which must still close the front window, since the whole point of that handler is that a window owns Escape and the top of it is exactly where that could be taken away; two arms fail on the v12.98 fixture.
