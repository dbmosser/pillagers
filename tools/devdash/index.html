CLAUDE HELPERS

Three Claude workers that write fixes for the game on their own, paid from your Claude Console credits. Each works on one job at a time.

CONSOLE MONEY

Your $200 of Claude Console credits. The helpers spend it as they work, a few dollars per job, with no rush and no waste, until it runs out. These are estimates; the Console Billing page has the exact balance.

QUALITY CHECK LINE

Every fix must pass the game's automatic tests before it goes into the game. Fixes wait here one at a time. A fix that fails is sent back to its helper to try again.

JUST ADDED TO THE GAME

The latest changes saved into the game (and backed up to GitHub). "Test update" means a change to the automatic tests, not the game itself.

YOUR PC

How hard your computer is working on the game right now. It always keeps at least 6 GB of memory free for you.

BACKGROUND RUNNER

A program that runs all day and night with no Claude cost: it starts the crash-hunting robots, re-runs all the tests on new versions, backs up the game, and keeps the helpers going.

QUESTIONS FOR YOU

When a helper has to make a call it is not sure about, it picks the best option, keeps going, and writes the question here for you.
